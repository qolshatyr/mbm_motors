# MBM Motors

### Каталог автозапчастей с интеграцией CloudShop

Сайт для поиска запчастей, просмотра цен и наличия по местам хранения и подготовки заявок на самовывоз. CloudShop остаётся основной системой товарного учёта; сайт использует локальный каталог в PostgreSQL.

**Статус:** в разработке. Синхронизация, каталог, поиск и корзина реализованы. Оформление и передача заявок — следующий этап.

---

## Возможности

- **Каталог:** карточки товаров, фотографии с заглушкой и постраничная выдача.
- **Поиск:** по названию, артикулу и коду, включая артикулы без дефисов.
- **Цены и наличие:** отдельно для Car City, БАКОРДА, жибек жолы АВТО и СКЛАДА.
- **Фильтры:** выбор места хранения и товары с положительным остатком.
- **Корзина:** добавление, изменение количества, удаление и очистка.
- **Проверка позиций:** серверный расчёт суммы, контроль остатков и отдельное подтверждение изменившейся цены.
- **Синхронизация:** полный импорт и инкрементальные обновления CloudShop с сохранением контрольной точки.

Корзина хранится в серверной сессии и не резервирует товар. Места хранения и точки самовывоза различаются; список точек выдачи ещё согласуется.

## Технологии

| Область | Стек |
|---|---|
| Backend | Java 21, Spring Boot 4.0.8, Spring MVC |
| Интерфейс | React, TypeScript, Vite, Tailwind CSS 4; каталог, карточка и корзина |
| Серверные страницы | Thymeleaf, Bootstrap 5.3.8; сохраняются во время перехода |
| Данные | PostgreSQL 17.6, Spring Data JPA, JdbcTemplate, Flyway |
| Интеграция | Spring RestClient, CloudShop API |
| Защита | Spring Security, CSRF, серверная валидация |
| Сборка и проверки | Maven Wrapper, JUnit, Mockito, Testcontainers, Spotless, JaCoCo |

## Разработка

Для локальной работы нужны Java 21 и PostgreSQL. Maven запускается через Wrapper; `compose.yml` поднимает локальную базу данных.

Настройка окружения, первичный импорт, запуск каталога и проверки описаны в [руководстве для разработки](docs/Development_Guide.md).

Новый frontend запускается отдельно: `cd frontend`, `npm ci`, `npm run dev`. Он читает тот же Spring Boot API; backend должен работать на порту 8080. [Архитектура и настройка темы](docs/Frontend_Architecture.md).

Основные команды проверки:

```sh
./mvnw verify
python3 -m unittest discover -s tests -v
```

Изменения выполняются в отдельных ветках и проходят через pull request. Порядок работы — в [GitHub Workflow](docs/GitHub_Workflow.md).
