# Интерфейс MBM Motors

Каталог, карточка товара и корзина на React, TypeScript, Vite и Tailwind CSS. Требуется Node.js ≥22.12.0. Версии закреплены в `package-lock.json`.

```sh
cd frontend
npm ci
npm run dev
npm run build
```

В режиме разработки откройте `http://127.0.0.1:5173/`. Spring Boot должен работать на `http://127.0.0.1:8080`: Vite передаёт ему `/api`, `/catalog`, `/cart`, `/images`, `/css` и `/webjars`. React-маршруты: каталог `/`, карточка `/products/:id?store=...`, корзина `/basket`. Прежние серверные страницы `/catalog` и `/cart` остаются доступны; обе версии используют одну cookie-сессию на том же адресе браузера. Если сервер открыт отдельно через `localhost`, это другая cookie-сессия.

## Границы состояния

- `app/`: оболочка приложения.
- `features/catalog/`: поиск, фильтры, товары и пагинация.
- `features/product/`: карточка и предложения по точкам.
- `features/cart/`: серверный снимок корзины, изменение количества и подтверждение цены.
- `shared/api/`: типы контракта и запросы с AbortSignal.
- `shared/ui/`: состояния загрузки, ошибок и пустой выдачи.
- URL хранит `q`, `store`, `available`, `page`. Изменение фильтра сбрасывает страницу. React Query отменяет устаревшие запросы; каталог обновляется раз в минуту и при возврате фокуса. Фоновая ошибка явно заменяет выдачу сообщением, чтобы устаревшие остатки не выглядели текущими.

Корзина, цены и остатки принадлежат серверу. Интерфейс не хранит корзину в localStorage и не обращается к CloudShop. Контракты: `../postman/specs/catalog.openapi.yaml`, `../postman/specs/cart.openapi.json`.

Изменения корзины сериализуются и блокируют остальные действия до завершения; оптимистичных изменений и автоматических повторов POST нет. CSRF-токен запрашивается через `/api/csrf` и хранится только в памяти; после 403 следующий ручной запрос получает новый токен. Успешный POST возвращает снимок корзины для общей суммы и счётчика. При ошибке выполняется GET для проверки фактического состояния; повторное действие выбирает пользователь. Снимок обновляется раз в минуту и при возврате фокуса. Подтверждение цены передаёт точную десятичную строку сервера без преобразования в JavaScript number.

Для отдельного тестового backend можно запустить `MBM_BACKEND_URL=http://127.0.0.1:8081 npm run dev -- --port 5175`. Переменная используется только локальным Vite proxy и не встраивается в клиентскую сборку.

Удаление и очистка требуют подтверждения в диалоге с первоначальным фокусом на «Отмена». Оформление заявки ещё не реализовано.

## Изменение оформления

Палитра, шрифт и размеры находятся в `src/styles/theme.css`: `@theme`, `--content-width`, `--radius`. Шрифты поставляются локально из Fontsource, внешние CDN не используются. Изменяйте общие токены прежде отдельных компонентов.

`dist/` — результат сборки. Подключение production-раздачи через Spring/reverse proxy требует отдельной настройки: этот этап использует локальный Vite proxy; `vite preview` проверяет только статические файлы и не предоставляет backend proxy.
