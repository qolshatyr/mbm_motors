# Живой стенд

Рабочая версия портала на этом компьютере: настоящий каталог CloudShop (обновление каждые
5 минут, только GET), вход партнёров, оформление и передача заявок в CloudShop непроведёнными
продажами, служебный просмотр заявок. Для показа клиенту стенд открывается наружу через
временный туннель Cloudflare (`https://*.trycloudflare.com`, без аккаунта). Это стенд для
проверок и презентаций, не рабочий хостинг: он доступен, пока компьютер включён и скрипт
запущен, а адрес меняется при каждом запуске туннеля.

## Команды

```sh
scripts/live_stand.sh start     # база, приложение и туннель; печатает адреса
scripts/live_stand.sh local     # без туннеля, только http://127.0.0.1:18080
scripts/live_stand.sh status
scripts/live_stand.sh stop
scripts/live_stand.sh partner <логин> "<компания>" "<контакт>" <телефон>   # пароль спросит скрыто
```

Состояние хранится в `~/.local/share/mbm-motors/` (каталог закрыт для других пользователей):
PostgreSQL 17.6 и её данные, `app.jar`, `stand.env` (доступ сотрудника), `accounts.txt`
(логины и пароли стенда), журналы. Токен CloudShop берётся из `.env` репозитория и не
выводится.

После изменений кода пересоберите и замените JAR:

```sh
(cd frontend && npm run build -- --base=/frontend/) && ./mvnw -q -DskipTests package -Prelease-site
cp target/mbm-motors-0.0.1-SNAPSHOT.jar ~/.local/share/mbm-motors/app.jar
scripts/live_stand.sh stop && scripts/live_stand.sh start
```

## Что важно

- **Каждая заявка на стенде создаёт настоящую непроведённую продажу в CloudShop.** Все
  партнёры стенда привязаны к карточке «тестовый покупатель», поэтому такие продажи легко
  найти и удалить. Не проводите их.
- Заказать можно только позиции СКЛАДА с ценой больше нуля (на 20.10.2026 — 121 позиция).
- Служебный раздел: `/admin/login`, логин `staff` — «Клиенты» (создание учётных записей, новый пароль, блокировка) и «Заявки». Создание карточек CloudShop на стенде включено (`MBM_ADMIN_CREATE_CUSTOMERS=true` в `stand.env`, с 22.10.2026 после контрольного теста): каждый новый клиент сразу получает настоящую карточку покупателя в CloudShop. Если карточка не нужна, удалите строку из `stand.env`, перезапустите приложение и укажите клиенту ID «тестового покупателя» `6ac110842dd87801040fed88`.
- Уведомления сотрудникам в Telegram (с 23.10.2026): добавьте в `stand.env` `MBM_ALERT_TELEGRAM_BOT_TOKEN` и `MBM_ALERT_TELEGRAM_CHAT_ID` (настройка — `docs/Deployment.md`, раздел «Уведомления сотрудникам в Telegram») и перезапустите приложение. Ссылку в сообщении даёт `MBM_SITE_URL`; адрес туннеля меняется, поэтому на стенде её можно не задавать. При первом запуске придёт сообщение о старых несверенных UNKNOWN-заявках стенда.
- Туннель публичный: любой, у кого есть адрес, увидит страницу входа. Данные доступны
  только после входа партнёра; не публикуйте адрес и пароли.
