## ✅ Исходные решения

- Каталог учитывает четыре места: Car City, БАКОРДА, жибек жолы АВТО и СКЛАД. Это места хранения; список самовывоза ещё не определён.
- Выбран вариант отдельных карточек покупателей CloudShop. Повторно выбирать между отдельными карточками и общим покупателем не требуется.
- Актуально на12.10.2026: реализованы синхронизация, каталог, поиск, корзина, локальное оформление и служебный просмотр. HTTP-адаптер передачи проверен локально; реальные отправки выключены.
- Базовый объём ТЗ: русский язык, тенге, самовывоз, оплата при получении, без регистрации. Сайт передаёт непроведённую продажу; сотрудник обрабатывает её в CloudShop.
- Сайт не обещает автоматический резерв. Тестовые продажи уже создавались; их создание не повторяется в рамках этого согласования.

## 🛠️ Проверки разработчика после ответов

Это не вопросы выбора технологий для клиента. Клиент предоставляет правила, ответственных и доступы; разработчик проверяет реализацию.

- [ ] Сверить актуальный контракт и права API покупателей; проверить формат телефонов и ограничения сопоставления. Использовать отдельные карточки без раскрытия и перезаписи чужих данных.
- [ ] Проверить категории, метки, доступность фотографий и непустые ответы удалений; связать это с согласованным правилом публикации.
- [ ] Проверить изменение только остатков и лимиты API; подобрать расписание синхронизации под фактические возможности.
- [ ] Реализовать серверную проверку заявки, снимок позиций, транзакционное сохранение и задачу передачи, защиту от двойной отправки.
- [ ] Проверить сбои создания покупателя и продажи, в том числе неопределённый результат, на локальных имитациях. Не повторять существующие тестовые продажи; любые новые внешние записи — только по отдельному согласованному сценарию.
- [ ] Проверить доступ сотрудников, CSRF, ограничение частоты заявок, защиту секретов, мобильное оформление, HTTPS и восстановление резервной копии.
