# Классификация каталога

`tools/catalog/classify_products.py` разбирает выгрузку товаров CloudShop (xlsx) и по
наименованию определяет категорию, бренд, марку, модель, кузов, годы, двигатель,
положение детали и ячейку склада. В выгрузке поля «Категория», «Группа», «Страна» и
«Поставщик» пустые, поэтому источник — только наименование.

```sh
python3 -m venv .venv-catalog && .venv-catalog/bin/pip install openpyxl
.venv-catalog/bin/python tools/catalog/classify_products.py docs/catalog-<id>.xlsx docs/catalog/Catalog_Classification.xlsx
```

Выгрузка и результат в Git не попадают: в выгрузке есть себестоимость и закупочные цены,
результат пересобирается командой выше.

## Листы результата

| Лист | Содержимое |
|---|---|
| Сводка | Доля распознанных полей и правила |
| Товары | Одна строка на товар; жёлтым — строки с замечаниями в колонке «Проверить» |
| Применимость | Одна строка на автомобиль: марка, модель, кузов, годы, двигатель (формат `docs/cloudshop/templates/product_fitment.csv`) |
| Категории | Дерево групп и число товаров |
| Бренды, Модели | Справочники с количеством |
| Нераспознанные слова | Латинские слова, которые не удалось отнести к бренду или модели, с примером |

## Метки для CloudShop

```sh
python3 tools/catalog/fill_categories.py docs/catalog-<id>.xlsx docs/catalog/catalog-<id>-categories.xlsx
```

Копия выгрузки, в которой изменена только колонка «Категория» (метки CloudShop через «, »):
раздел, подраздел, марки с моделями и «Бренд …», например «Ходовая часть, Амортизаторы и
опоры, Hyundai, Sonata, Kia, Optima, Бренд HPT». Файл правится на уровне XML: остальные ячейки и
части книги не меняются. Рядом создаётся `…-test5.xlsx` из пяти товаров для пробного импорта.
Названия групп не содержат запятых, иначе одна метка распалась бы на две.

С `--makes-only` модели в метки не попадают — только раздел, подраздел, марки и бренды
(решение пользователя 20.10.2026: пока делить детали только по марке):

```sh
python3 tools/catalog/fill_categories.py --makes-only docs/catalog-<id>.xlsx docs/catalog/catalog-<id>-makes.xlsx
```

Импорт копирует всю выгрузку, включая цены и остатки, поэтому файл строят из свежей выгрузки
или перед импортом сверяют её с CloudShop.

## Правила

- Годы «11-» — с 2011, «98-05» — 1998–2005, «(-2011)» — по 2011. Годы относятся ко всем
  моделям, перечисленным перед ними: «ACCENT/SOLARIS RIO 11-» — все три с 2011.
- Коды кузова (YF, MD, LM, DN8…) уточняют модель; короткие коды учитываются только рядом
  с моделью или в скобках.
- Склейки вида «LEON-HPT» дают несколько брендов; «ORIG» — оригинал Hyundai/Kia.
- Исправляются слитные слова («передHY»), похожие буквы другого алфавита («Fе») и частые
  опечатки моделей.
- Справочники и порядок правил — `tools/catalog/catalog_rules.py`; новые бренды и опечатки
  добавляются туда, затем результат пересобирается.

Это автоматическое предложение: применимость и категории нужно выборочно проверить перед
публикацией фильтров на сайте или загрузкой меток в CloudShop.
