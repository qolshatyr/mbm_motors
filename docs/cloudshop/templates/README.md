# Таблицы подготовки каталога

Используйте как рабочие листы в Excel/Google Sheets. Это не формат импорта CloudShop. Первые два CSV пустые, кроме заголовков; catalog_groups.csv содержит только предложенную структуру, без реальных ID. Код G01 — внутренний код проекта структуры, не CloudShop ID.

Перед загрузкой в Excel используйте «Данные → Из текста/CSV» и задайте идентификаторы/артикулы текстом до загрузки; автоматическое определение типов отключить. Если импорт содержит шаг автоматической смены типов, удалите его перед назначением текстовых типов. Двойной щелчок может потерять ведущие нули и точность длинных числовых кодов; UTF-8 BOM защищает только кириллицу.

## products_to_prepare.csv

| Поля | Как заполнять |
| --- | --- |
| product_id | Существующий ID CloudShop; если неизвестен, оставить пустым до проверки разработчиком |
| sku, brand, oem_numbers | Точный артикул, производитель детали, подтверждённые OEM-номера; несколько номеров разделять знаком `|` |
| current_name, target_name | Исходное и предлагаемое понятное название |
| current_unit, target_unit | Исходная и подтверждённая единица; не ставить шт без проверки учёта |
| sale_basis | Что получает покупатель за1: деталь, канистра, физическая коробка, литр и т.п. |
| pack_quantity | Сколько базовых учётных единиц в упаковке; пусто, если упаковка не используется |
| group_path | Полный согласованный путь группы из catalog_groups.csv |
| tags | Предлагаемые метки, разделённые `|`; они пока не импортируются сайтом |
| photo_1, photo_2 | Имя исходного файла для загрузки либо проверенный публичный HTTPS URL; не закрытая ссылка |
| description | Состав, сторона, крепления и подтверждённые ограничения |
| public_state | Проектный статус: draft / approved / hold / excluded; не активный переключатель публикации |
| verification_state | not_checked / needs_review / confirmed |
| confirmed_by, notes | Кто подтвердил и что ещё проверить |

Исходные цены и остатки по магазинам хранить в отдельной выгрузке/GET-снимке, связанной с карточками. Этот шаблон не предназначен для смены учётной схемы или пересчёта остатков.

## product_fitment.csv

Одна строка = один существующий товар и одна подтверждаемая модификация автомобиля. ID одной детали может повторяться, карточку в CloudShop не дублируют.

- make/model/generation — марка, точная модель и поколение/код кузова.
- year_from/year_to — подтверждённые годы; неизвестное оставить пустым.
- engine_code/transmission/drive/body_type/market — ограничения конкретной совместимости.
- position — сторона и ось установки.
- restrictions — дополнительные ограничения, даты выпуска, комплектация.
- evidence/evidence_date — проверенный источник и дата проверки.
- confirmed_by — ответственный специалист.
- state — draft / confirmed / rejected.

Пустое поле не означает универсальную совместимость. Полноту и ограничения подтверждает специалист; описания не извлекаются автоматически из названия детали.

## catalog_groups.csv

- group_code — код строки структуры в этой таблице.
- parent_code — код родительской строки; пусто для верхнего уровня.
- name/group_path — название и полный путь.
- state=proposal — структура пока предложена, клиентом не утверждена.

После утверждения можно добавлять реальные CloudShop ID в отдельный столбец согласованной рабочей копии. Не использовать проектные коды в запросах CloudShop.
